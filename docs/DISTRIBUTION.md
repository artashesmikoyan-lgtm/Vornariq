# Distribution candidates — review before sharing

Research date: **2026-10-05**. These are potential venues, not endorsements or
permission to post. TASK-016 creates no accounts, messages, submissions, or list
PRs. Use a separately approved final draft and target; recheck community rules
and category fit immediately before any later action.

Lead with the [demo](DEMO.md), MIT source, and explicit limitations. Ask for
install/first-run feedback rather than stars. Track volunteered outcomes using
[ADOPTION.md](ADOPTION.md), with no tracking SDK.

## Suggested later sequence

Start with a small relevant audience and ask whether install → doctor → Codex
execution worked. Fix demonstrated onboarding blockers, then consider one
broader technical write-up or Show HN. Record dates and actual feedback without
equating impressions, downloads, or stars with users. Review
[launch drafts](LAUNCH_COPY.md) before any separately authorized distribution.
